# Vyntric Community — Official Minecraft SMP & Competitive Lineup Portal

> **Build • Survive • Conquer**  
> Official web platform for the Vyntric Minecraft SMP realm, featuring competitive team rosters, tier lists, live player stats, and Google-authenticated member whitelisting.

---

## 🌟 Key Features

- **The Roster (16 Core Members Lineup):**
  - Complete competitive breakdown (#01–#16) with individual IGNs, Discord handles, and custom profiles.
  - Interactive Gamemode Tier Breakdown Modal with dynamic progress bars (Sword, NetPot, DiaPot, UHC, SMP, Axe, Crystal, Mace).
  - Real-time client-side search and gamemode circuit filtering.
- **Pure Animation Background:**
  - 100% pure cinematic Minecraft trailer looping seamlessly in the background without ratings, promos, or logos.
- **Audio Pod:**
  - Background ambient soundtrack with volume slider and audio equalizer.
- **Member Authentication & Whitelist:**
  - Google Sign-In with real-time Minecraft IGN linking.
- **Admin Control Panel:**
  - Dynamic roster management, role assignments, and member permissions with instant synchronization.
- **Vercel & Node.js Ready:**
  - Dual-port local server (`server.js`) with HTTP range-request streaming, plus `vercel.json` for seamless static deployment.

---

## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/insanenibir-commits/Vyntric-Community.git
   cd Vyntric-Community
   ```

2. Start the local server:
   ```bash
   node server.js
   ```
   Or open with any static web server / VS Code Live Server.

3. Open in your browser:
   - Web App: `http://localhost:3000` (or port 8080)
   - Squad & Roster: `http://localhost:3000/squad.html`
   - Admin Panel: `http://localhost:3000/admin.html`
